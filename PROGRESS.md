- **2026-09-02** — Webhooks pass (ADR-0014): `/[locale]/webhooks` rebuilt as the log of callbacks the app **receives** — the prototype's outbound-delivery fiction (rows delivering to `api.merchant.com/webhooks/stripe` with 200/500 and "24ms" latency, `1,024 results`, dead filters, `bg-white` literals) is gone, because INTEGRATION.md §7 (:99/:307) fixes the direction: this app receives, it does not deliver. `server/data/webhooks.ts`: `WebhookEvent` store (`__kineticWebhooksStore`, 7 seeded callbacks — both money events reference real ledger `referenceId`s; one seeded retry; one unknown type flagged unhandled; both refusal paths with reasons) where **status is a stored receive-time fact** (RECEIVED/DUPLICATED/REJECTED — the one deliberate departure from derive-everything: a log row is append-only history), `listWebhooks` (q over event id/type/payload, `?status`, `?type` with `unknown` = unhandled, 10/page), `recordInbound` (dedupe by `eventId` → DUPLICATED row with first-received reference) and `rejectInbound` (REJECTED + raw body).
